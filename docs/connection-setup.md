# ワークスペースから接続する

1. WordPressの連携設定で、業務接続の共有キー、実行ユーザーと公開する業務を一度設定します。
2. Fourmix IntelligenceのワークスペースでWordPress接続を追加し、このサイトのURLと同じ共有キーを入力して「接続して設定を同期する」を実行します。
3. WordPressの設定画面に接続中のワークスペースが表示されます。ログイン先、テナントや接続IDは手入力しません。
4. 社員は「社内向けAIの設定」からFourmix Intelligenceにログインして戻り、Studio AIを選びます。共有業務接続を個人ごとに作り直す必要はありません。

お客様向けAIの公開トークンは、公開する場合だけ設定します。社内助手の本人ログインとは別の設定です。Studioで決めた社内・社外の範囲を変更しません。

接続を別の環境へ移す場合は、管理者が新しい共有キーを保存してから接続し直します。接続情報だけを解除し、投稿・注文・会話履歴・添付・監査は削除しません。旧キーの変更前に保存した本人確認用の接続情報がある場合、同じ接続への更新だけを受け付けます。

プラグインを通常どおり更新すれば追加のDBマイグレーションは不要です。旧ワークスペース・接続の組を保持したまま、同じ接続での次回確認時に自動設定へ移行します。署名済み機能一覧の取得だけでは新しい接続先を固定しません。

独立したローカルDockerで`wp eval-file tests/connection-bootstrap-integration.php`を実行し、署名・URL検証、再利用拒否、初回と再接続、別環境の拒否、旧設定の保持、失敗時の部分設定防止を検証します。`wp eval-file tests/personal-settings-prerequisites.php`では、未接続・設定不足時の案内、相談画面の状態、設定済みのログイン導線、設定権限のない担当者向け表示も確認します。実運用の設定やキーは使用しません。
