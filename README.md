# Fourmix Intelligence for WordPress

Fourmix Intelligence の AI 接客、サイト内案内、資料同期を WordPress と WooCommerce へ統合する公式プラグインです。

## 主な機能

- AIコンシェルジュとAIサイト内検索
- 現在のページに応じた関連記事案内
- WooCommerce の商品提案、まとめ買い、カート確認
- ページを移動しても続けられる会話と、画面内だけの一時会話
- 投稿・固定ページ・カスタム投稿・商品のイベント駆動型差分同期
- WordPress 管理画面だけで完結する設定
- 同一サイト確認、レート制限、秘密情報のサーバー側保持
- プライバシーポリシー作成支援
- WordPress 6.9 以降の Abilities API から利用できる編集担当者向けAI能力
- ワークスペース版 FinCube から投稿、メディア、利用者、WooCommerce の商品・注文・クーポンを扱う署名付き業務接続

各ブロックは単にチャットを開くものではありません。関連記事やまとめ買いは自動で結果を表示し、質問が必要な機能だけ入力欄を使います。WooCommerce が未導入の場合は商品向けブロックだけを停止します。

## FinCube からの業務操作

「設定」→「Fourmix Intelligence」で32文字以上の接続共有キーを設定し、FinCubeへ許可する業務だけを選びます。Fourmix Intelligence のワークスペース接続にはサイトURLと同じ共有キーを登録します。公開される操作一覧は毎回 WordPress から取得され、管理画面で無効にした業務は次の実行から利用できません。

接続共有キーを変更すると、それまでのワークスペースとの結び付けは解除されます。新しい接続先で同じキーを設定してから再接続してください。更新・削除などの操作は署名、有効期限、再送防止、ワークスペースとの結び付けを確認した上で実行されます。

## インストール

リリースの ZIP を WordPress 管理画面「プラグイン」→「プラグインを追加」→「プラグインのアップロード」からインストールします。設定は「設定」→「Fourmix Intelligence」にあります。

## 商品情報の扱い

商品名、説明、分類、商品IDなど検索に必要な情報だけを差分同期します。在庫のように頻繁に変わる情報は索引へ反映せず、最終表示や購入時には WooCommerce の最新状態を利用します。AI の構造化結果に含まれる商品リンクも回答文とは別に表示します。

## 開発

WordPress 6.7 以降、PHP 8.1 以降を対象にしています。ビルドツールなしでも配布 ZIP が動作するよう、実行に必要な JavaScript と CSS を同梱しています。
