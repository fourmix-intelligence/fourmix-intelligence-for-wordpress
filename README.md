# Fourmix Intelligence for WordPress

Fourmix Intelligence の社内向け業務支援とお客様向け案内を、WordPress の管理画面・公開ブロックへ接続する公式プラグインです。AIはすべてFourmix IntelligenceのStudioで作成し、このプラグインでは利用するAIと業務の許可を選びます。

## 主な機能

- AIコンシェルジュとAIサイト内検索
- 現在のページに応じた関連記事案内
- WooCommerce の商品提案、まとめ買い、カート確認
- ページを移動しても続けられる会話と、画面内だけの一時会話
- 投稿・固定ページ・カスタム投稿・商品のイベント駆動型差分同期
- WordPress 管理画面だけで完結する設定
- 同一サイト確認、レート制限、秘密情報のサーバー側保持
- プライバシーポリシー作成支援
- WordPress 6.9 以降の Abilities API から利用できる編集担当者向けAI能力
- ワークスペース版 FinCube から投稿、メディア、利用者、WooCommerce の商品・注文・クーポンを扱う署名付き業務接続

各ブロックは単にチャットを開くものではありません。関連記事やまとめ買いは自動で結果を表示し、質問が必要な機能だけ入力欄を使います。WooCommerce が未導入の場合は商品向けブロックだけを停止します。

## FinCube からの業務操作

「設定」→「Fourmix Intelligence」で32文字以上の接続共有キー、接続の実行ユーザー、許可する業務を選びます。実行ユーザーの設定がない接続は拒否されます。Fourmix Intelligence のワークスペース接続にはサイトURLと同じ共有キーを登録します。公開される操作一覧は毎回 WordPress から取得され、管理画面で無効にした業務と実行ユーザーに権限のない業務は利用できません。

接続共有キーを変更すると、それまでのワークスペースとの結び付けは解除されます。新しい接続先で同じキーを設定してから再接続してください。更新・削除などの操作は署名、有効期限、再送防止、ワークスペースとの結び付けを確認した上で実行されます。

## インストール

リリースの ZIP を WordPress 管理画面「プラグイン」→「プラグインを追加」→「プラグインのアップロード」からインストールします。設定は「設定」→「Fourmix Intelligence」にあります。

## 管理画面からの業務支援

管理メニュー「Fourmix Intelligence」→「本人のAI設定」で、本人の短期接続とStudioの社内向けAIを選びます。「AIに相談」は会話専用のページです。編集権限を持つ利用者は通常の管理画面右下から同じ会話を開けます。ページと浮窓を切り替えても未送信の入力や添付を維持します。現在の画面名や投稿の情報は明示選択時だけ送信し、本文や一覧の行データは含めません。業務操作は本人のWordPress権限を使い、更新のプレビューと明示確認を経て実行します。直接の業務操作は専用ページにあります。お客様向けAIにはこの入口を公開しません。

お客様向けAIは設定画面の専用一覧から選び、既存のネイティブブロックで公開します。WooCommerceと予約プラグインは実際の導入状態を判定します。予約プラグインの検出だけでは予約操作を有効にしません。

利用手順、認可の区別、検証結果と未検証の範囲は[業務支援の導入と検証](docs/native-operations.md)を参照してください。

開発版 `2.0.0-dev` では、管理画面と公開画面に逐次応答・連続メッセージ・受信停止・通信断後の結果照会・確認カードを備えています。回答のMarkdown、表、コード、Mermaidの図を表示でき、表や回答のコピー、図の拡大に対応します。添付が許可されたAIでは画像・文書を選択し、プレビュー、転送進捗、保存確認、取り除き、結果照会を利用できます。保存結果を確認するまでメッセージは送信しません。公開相談は `[fourmix_intelligence_chat]` でも配置できます。会話専用tokenはサーバーへ移し、旧版の公開会話は新しい相談を開始する契約へ変更しています。画面の使い方と実ブラウザーの証跡は[ネイティブ相談画面の検証](docs/native-chat-acceptance.md)、同梱部品は[表示部品とライセンス](docs/chat-display-dependencies.md)を参照してください。

## 商品情報の扱い

商品名、説明、分類、商品IDなど検索に必要な情報だけを差分同期します。在庫のように頻繁に変わる情報は索引へ反映せず、最終表示や購入時には WooCommerce の最新状態を利用します。AI の構造化結果に含まれる商品リンクも回答文とは別に表示します。

## 公開AIとリバースプロキシ

公開会話 API は scheme・host・実効 port を含めて同じサイトか確認します。Origin 不一致は403、回数超過は429です。拒否理由は `fourmix_intelligence_public_request_denied` アクションに `origin_mismatch`、`invalid_client_ip`、`rate_limited` のコードで通知します。本文、IP、トークンはこの通知へ含めません。

既定では転送ヘッダーを信頼せず、接続元IPを使用します。プロキシ経由の場合は管理者が `wp-config.php` に実際のプロキシIPまたはCIDRだけを指定してください。

```php
define( 'FOURMIX_INTELLIGENCE_TRUSTED_PROXIES', array( '192.0.2.10', '2001:db8:2::/64' ) );
```

上記は説明用のアドレスです。プロキシは X-Forwarded-For に実際の接続元を正しく追記してください。直接の接続元が許可範囲内のときだけ右側の信頼するプロキシを除き、最初の非信頼IPを利用者として扱います。任意の転送ヘッダーや `Forwarded` は認可根拠にしません。全インターネットを信頼範囲へ指定しないでください。

## 開発環境

WordPress 6.7 以降、PHP 8.1 以降を対象にしています。ビルドツールなしでも配布 ZIP が動作するよう、実行に必要な JavaScript と CSS を同梱しています。
